# Plugin: Tabs

Short-term running tabs for customers (bar or canteen style), settled later.

## Benefits of a plugin over building it into the core
- **Turned on only where it fits:** hospitality-style orgs use it; others never see it.
- **Can evolve separately from Khata:** overdue rules and write-off policy can change without affecting core or Khata.
- **Each org's data stays separate:** suspension and read-only rules apply automatically.
- **Can be removed cleanly:** it has its own tables and migrations, so retiring it later doesn't touch core.
