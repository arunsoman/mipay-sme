# Plugin: Accounting Export

Pushes the journal to Xero, QuickBooks or Sage, or exports CSV.

## Benefits of a plugin over building it into the core
- **Read-only:** it can't change ledgers.
- **One connector per accounting package:** each can be added or removed without touching the platform.
- **Credentials kept per org:** each org's accounting account stays inside the plugin.
- **Billable add-on:** for orgs that need bookkeeping integration.
