# Plugin: Expenses & Petty Cash

Staff log expenses with photo receipts, and an admin approves them.

## Benefits of a plugin over building it into the core
- **Low risk, high value:** no core changes, and it can be turned on for any org.
- **Reuses org roles:** STAFF submit and ADMIN approve, with the second-person rule.
- **Optional:** orgs that don't track expenses in MiPay never see it.
- **Feeds Accounting Export:** without touching the ledgers.
